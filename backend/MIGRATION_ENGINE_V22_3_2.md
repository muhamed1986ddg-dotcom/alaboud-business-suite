# محرك ترحيل البيانات v22.3.2

ينقل البيانات من `app_state` أو ملف نسخة احتياطية JSON إلى جداول PostgreSQL العلائقية، داخل معاملة واحدة. لا يحذف `app_state` ولا يعدله.

## قبل التشغيل

1. خذ نسخة احتياطية من قاعدة البيانات.
2. اضبط `DATABASE_URL`.
3. نفّذ الترحيل أولاً على نسخة تجريبية من قاعدة البيانات.

## الأوامر

```bash
npm run migrate
npm run migrate -- --file ./alaboud-backup.json
npm run migrate:verify
npm run migrate:verify -- --run <RUN_ID>
npm run migrate:rollback
npm run migrate:rollback -- --run <RUN_ID>
```

الترحيل يستخدم `ON CONFLICT DO NOTHING`، لذلك لا يستبدل السجلات العلائقية الموجودة. يسجل كل تشغيل في جدول `data_import_runs` مع الأعداد والمعرّفات التي أضيفت. التراجع يحذف فقط السجلات التي أضافها تشغيل محدد، وبترتيب يحترم العلاقات.

## حدود هذه المرحلة

- واجهات API ما زالت تقرأ وتكتب من `app_state`.
- الجداول العلائقية هي نسخة مرحّلة للتحقق والتحضير للمرحلة التالية.
- بيانات الشركاء الإضافية والسجلات غير الممثلة بأعمدة مستقلة محفوظة كاملة في `raw_payload`.
