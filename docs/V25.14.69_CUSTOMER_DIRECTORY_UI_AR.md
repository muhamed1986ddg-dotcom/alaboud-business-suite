# الإصدار 25.14.69 — تحسين واجهة قائمة العملاء

## التغييرات

- صارت قائمة العملاء تستخدم شبكة البطاقات الداكنة نفسها المستخدمة في قائمة العملاء المتأخرين.
- بقيت وظائف فتح الحساب وتصفير الحساب والتعديل والحذف دون تغيير.
- أصبح رقم العميل ظاهرًا داخل البطاقة.
- أصبح مربع البحث واضحًا في دعم الاسم ورقم العميل ورقم الهاتف.
- صار البحث الرقمي يتجاهل المسافات والشرطات وأقواس رقم الهاتف، ويدعم الأرقام العربية والفارسية.
- صار زر حفظ صورة كشف الحساب صغيرًا وبجوار زر مشاركة الصورة.

## التحقق

- اختبار انحدار خاص بالواجهة والإجراءات.
- اختبار بحث PostgreSQL بالأرقام المنسقة.
- بناء Vite للإنتاج واختبارات الإصدار الكاملة.
