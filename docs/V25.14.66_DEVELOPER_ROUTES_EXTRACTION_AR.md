# v25.14.66 — Architecture Stage 2

## الهدف

متابعة تفكيك `backend/src/server.js` تدريجيًا دون تغيير السلوك أو منطق البيانات المالية.

## الاستخراج المنفذ

نُقلت مسارات منصة المطور إلى وحدة مستقلة:

- إدارة مفاتيح API وعملية الإلغاء.
- إدارة Webhooks واختبار الاتصال وتعطيلها.
- قراءة سجل التكامل من PostgreSQL.

المسار الجديد:

```text
backend/src/routes/developer.js
```

## ضمانات السلوك

- بقيت جميع المسارات محمية بالمصادقة ودور `ADMIN`.
- لا تظهر بصمات مفاتيح API أو أسرار Webhook في استجابات القائمة.
- بقي حد سجل التكامل بين 1 و500 سجل.
- بقي فحص Webhook ضد العناوين الداخلية وغير الآمنة.
- لم تتغير مسارات العملاء أو الحوالات أو الديون أو الأرباح أو المصروفات أو رأس المال.
- يبقى `maxScale=1` لأن الحالة التفاعلية الحالية تعتمد على `app_state` ونسخة الذاكرة الأحادية.

## الاختبارات

أضيف اختبار انحدار يتحقق من المسارات الثمانية، والمصادقة، وإخفاء الأسرار، وحد سجل التكامل، وترتيب التسجيل داخل الخادم، ومنع اعتماد الوحدة على ملفات الحسابات المالية.
