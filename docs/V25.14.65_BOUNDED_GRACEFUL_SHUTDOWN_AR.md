# v25.14.65 — إغلاق Cloud Run المحدود زمنيًا

## الهدف

ضمان أن إغلاق مراجعة Cloud Run ينتهي قبل نافذة `SIGKILL` البالغة 10 ثوانٍ، مع إعطاء الأولوية للكتابات المالية المؤكدة وتسجيل مدة كل مرحلة.

## التغييرات

- مهلة إجمالية افتراضية مقدارها 8 ثوانٍ، وحد أمان صلب لا يتجاوز 8.5 ثانية.
- إيقاف قبول الطلبات وانتظار قصير للطلبات النشطة بمهلة محددة.
- انتظار سلسلتي write-behind و`saveDurable` قبل إغلاق PostgreSQL.
- تأكيد الكتابات durable أولًا، ثم تفريغ Telemetry بأفضل جهد، ثم إغلاق PostgreSQL pools.
- تفريغ Telemetry بأفضل جهد ضمن الوقت المتبقي فقط.
- وضع حد زمني لإغلاق مجموعات اتصالات PostgreSQL.
- تسجيل بداية الإغلاق، ومدة كل مرحلة، والمدة الإجمالية، ورمز الخروج.

## حدود النطاق

لا يغير هذا الإصدار منطق الأرباح أو الديون أو الحوالات أو أسعار الصرف أو شكل البيانات.

Graceful shutdown completed in ...ms (budget=8000ms, exitCode=0)
