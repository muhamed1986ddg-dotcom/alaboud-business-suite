# v25.14.117 — الأوامر الصوتية الآمنة

## المرحلة الأولى
- زر ميكروفون عائم على الكمبيوتر والهاتف.
- أوامر التنقل: الرئيسية، العملاء، المتأخرون، الحوالات، الخزنة، التقارير، أسعار الصرف، الديون، الشركات، رأس المال، المصروفات، الإعدادات، ومركز AI.
- البحث عن عميل وفتح حسابه بالصوت.
- سؤال مثل «كم رصيد العميل أحمد؟» يعرض الرصيد إذا كان موجودًا في نتيجة البحث.
- عرض الجملة التي تم التعرف عليها ورسالة النتيجة.

## الأمان
- لا تنفذ المرحلة الأولى أي POST/PATCH/PUT/DELETE صوتيًا.
- أوامر مثل إضافة حوالة، دفعة، تصفير حساب، تعديل أو حذف عميل تُرفض صوتيًا وتطلب فتح الشاشة والمراجعة.
- يعتمد التعرف الصوتي على Web Speech API في المتصفح، ويحتاج إذن الميكروفون واتصال HTTPS.
- لا تغيير على المحاسبة، الخزنة، WhatsApp، Scheduler، أو منطق المتأخرين.
