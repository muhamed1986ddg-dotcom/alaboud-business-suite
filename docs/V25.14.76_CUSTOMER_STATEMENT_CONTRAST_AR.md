# الإصدار v25.14.76 — وضوح كشف حساب العميل

## المشكلة

كشف الحساب احتفظ بخلفيته البيضاء القديمة، بينما نظام التصميم الداكن الموحد يفرض لونًا أبيض على المبالغ والعناصر المهمة. النتيجة كانت نصًا أبيض فوق خلفية بيضاء، خصوصًا الحساب القديم والدفعات والمجموع النهائي.

## الإصلاح

- جعل كشف الحساب المعروض داخل التطبيق داكنًا وعالي التباين.
- جعل العناوين ذهبية أو فاتحة، والقيم الأساسية واضحة، والدفعات خضراء، والإجمالي النهائي ذهبيًا.
- ضبط خلفيات وحدود صفوف الحوالات والدفعات ضمن نطاق كشف الحساب فقط.
- فصل نمط الطباعة: خلفية بيضاء ونص أسود عند الطباعة أو حفظ PDF.

## السلامة

التعديل بصري فقط. لم تتغير معادلات كشف الحساب أو الأرصدة أو بيانات PostgreSQL أو تطبيق Android الأصلي. Android shell يبقى v25.14.74 ويعرض Web/Backend v25.14.76 بعد نشر Cloud Run.
