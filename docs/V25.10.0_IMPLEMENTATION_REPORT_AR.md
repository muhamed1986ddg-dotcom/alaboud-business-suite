# تقرير تنفيذ الإصلاحات — v25.10.0

## المنفذ

1. **الحفظ الدائم:** أصبحت `mutateDurable` تنتظر تأكيد PostgreSQL، وتعيد حالة الذاكرة السابقة عند فشل الحفظ.
2. **المحرك المالي المركزي:** أضيف `backend/src/finance/FinancialEngine.js` وأصبح حساب رصيد العميل وإجمالي دين العملاء من مصدر واحد.
3. **اختبارات E2E:** أضيف اختبار تدفق مالي يغطي إضافة العميل، القراءة بعد الكتابة، الحوالة، الدفعة، تعديل الحوالة، إنشاء/تعديل/حذف الدين، وتطابق الرصيد.
4. **تقسيم الخادم:** نُقلت حسابات العملاء المالية ومسارات الصحة والتوثيق من `server.js` إلى وحدات مستقلة.
5. **تقسيم صفحة العملاء:** نُقل شريط الأدوات وعناصر البحث والفرز إلى مكونات مستقلة، وأضيف تحديث محلي فوري بعد إنشاء العميل مع تحقق صامت من الخادم.
6. **الفرز في PostgreSQL:** أضيفت أنماط: أعلى رصيد، آخر حوالة، الأكثر تأخرًا، الأقدم، الأحدث، والترتيب الأبجدي داخل Repository.
7. **CSS:** أضيف فحص يمنع القواعد المتطابقة غير المراجعة. التكرارات المتبقية مرتبطة بسياقات Responsive/Keyframes ومراجعة صراحةً.
8. **الملفات:** أزيلت README وnpmrc المتطابقة، وجرى توحيد أيقونة Android الدائرية مع الأساسية وحذف النسخ الثنائية المتطابقة. أصبحت نتيجة جرد SHA-256: صفر ملفات متطابقة.
9. **ملاحظات الإصدارات:** نُقلت الملاحظات القديمة إلى `docs/releases/archive` وأضيف تقرير موحد للإصدار الحالي.
