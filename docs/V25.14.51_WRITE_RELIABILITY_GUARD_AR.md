# v25.14.51 — Write Reliability Guard

هذا الإصدار يشدد موثوقية عمليات الكتابة المالية بدون تغيير أي معادلة مالية أو بنية بيانات.

- فرض `Idempotency-Key` بعد المصادقة على مسارات الحوالات والمدفوعات والديون العامة والمصروفات ورأس المال وحركات/دفعات الشركات.
- الطلب المالي بدون المفتاح يفشل بـ HTTP 428 بدل السماح بعملية قابلة للتكرار عند Retry.
- الاحتفاظ بآلية replay الحالية للطلب المكتمل و409 للعملية نفسها إذا كانت ما زالت قيد التنفيذ.
- إضافة فحص CI لتراجع تسريب PoolClient واختبار timeout recovery واختبار write reliability الجديد.
- إثبات أن الكتابات المتينة ما زالت تمر عبر `durableMutationChain` المتسلسلة، لمنع طلبين ماليين متزامنين من الحساب من نفس snapshot قبل commit.

لا يتضمن الإصدار رفع Isolation Level عالميًا ولا تغيير الجرد أو الأرباح أو أرصدة العملاء.
