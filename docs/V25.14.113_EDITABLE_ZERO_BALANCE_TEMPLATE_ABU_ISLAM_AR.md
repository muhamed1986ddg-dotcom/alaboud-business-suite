# v25.14.113 — قوالب WhatsApp القابلة للتعديل

- إضافة قالب مستقل لرسالة تصفير الحساب داخل إعدادات WhatsApp.
- حفظ القالب في Backend مع بقية إعدادات WhatsApp.
- المتغيرات المدعومة في قالب التصفير: `{customerName}` و`{name}`.
- تغيير التوقيع الافتراضي لقوالب WhatsApp التلقائية إلى «أبو إسلام».
- تغيير توقيع الرسائل اليدوية السريعة المرتبطة بالحوالة/الدفعة/التصفير إلى «أبو إسلام».
- لا تغيير على الحسابات أو الخزنة أو الأرباح أو قاعدة البيانات المالية.
