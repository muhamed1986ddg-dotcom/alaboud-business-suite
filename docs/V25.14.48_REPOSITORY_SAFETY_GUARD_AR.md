# v25.14.48 — حماية المستودع من الأسرار والنسخ الحساسة

هذا الإصدار أمني وقائي فقط ولا يغير منطق الحسابات أو قاعدة البيانات.

## ما تم إصلاحه

- إضافة `.gitignore` شامل لمنع رفع ملفات البيئة والأسرار والمفاتيح والشهادات وقواعد البيانات المحلية والنسخ الاحتياطية وملفات التصدير الحساسة ومخرجات البناء.
- إبقاء ملفات migrations الخاصة بالمشروع قابلة للتتبع داخل `backend/migrations/`.
- توسيع `scripts/check-sensitive-files.js` ليكشف أيضًا ملفات service account وcredentials وsecrets و`local.properties` وسجل shell إذا دخلت إلى Git.
- إضافة الأمر `npm run check:sensitive`.
- ربط فحص الملفات الحساسة بأمر `npm run build` بحيث يفشل البناء قبل النشر إذا وُجد ملف حساس غير مسموح به.

## ملاحظة مهمة

`.gitignore` يمنع الملفات الجديدة غير المتتبعة فقط. إذا كان ملف حساس قد دخل Git سابقًا، يجب حذفه من التتبع/التاريخ بشكل مستقل وتدوير أي مفتاح أو كلمة مرور كانت داخله.
