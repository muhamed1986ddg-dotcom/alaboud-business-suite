# الإصدار v25.3.0 — ضمان الحفظ وترقيم العملاء

- أصبحت عمليات العملاء والحوالات والدفعات والديون والمصروفات ورأس المال تنتظر نجاح الحفظ الدائم قبل إرسال استجابة النجاح.
- أضيف تسلسل للكتابات الحساسة لمنع تداخلها.
- عند فشل الحفظ تُعاد حالة الذاكرة إلى النسخة السابقة بدل إبقاء بيانات غير محفوظة.
- أضيف اختبار يحاكي فشل التخزين ويتحقق من ظهور الخطأ.
- أضيف ترقيم خادمي لقائمة العملاء بحجم 20 عميلًا في الصفحة.
- أضيف AppPagination، وإعادة الصفحة الأولى عند تغيير البحث أو الفرز.
- تستخدم نماذج الحوالة والدفعة قائمة خيارات عملاء خفيفة مستقلة.
