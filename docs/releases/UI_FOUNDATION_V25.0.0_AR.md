# v25.0.0 — UI Foundation (المرحلة الأولى)

## المنفذ فعليًا
- إنشاء مكتبة مكونات مشتركة في `frontend/src/components/ui/`.
- إضافة `AppModal`, `AppButton`, `AppCard`, `AppTable`, `AppStatCard`.
- تحويل صفحة أسعار الصرف لاستخدام المكونات المشتركة بدل `RateModal` والجدول المحلي.
- ربط `UnifiedModal` و`LoadingButton` القديمين بالمكونات الجديدة للمحافظة على التوافق.
- إنشاء Design Tokens وملف CSS خاص بالمكونات.
- توحيد استيراد CSS عبر `styles/index.css`.

## ملاحظة بنيوية
ملف `styles.css` القديم لم يُحذف في هذه المرحلة حتى لا تنكسر الصفحات التي لم تُرحّل بعد. أصبح خلف ملف دخول واحد، وسيتم تقليصه تدريجيًا مع تحويل بقية الشاشات إلى المكونات المشتركة.
