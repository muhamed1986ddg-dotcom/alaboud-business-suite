# الإصدار v25.2.0 — إكمال ترحيل الواجهة

- تحويل جميع جداول شاشات التطبيق إلى `AppTable`، مع دعم وضع التوافق للمحتوى القديم داخل مكوّن واحد.
- تحويل نوافذ الحوالات ورأس المال والإعدادات إلى `AppModal`.
- إزالة استخدام `<table>` وطبقات المودال اليدوية من مجلد `screens/`.
- إضافة فحص جودة آلي يمنع رجوع الجداول أو المودالات اليدوية مستقبلًا.
- الحفاظ على جداول الطباعة المستقلة خارج شاشات التطبيق عند الحاجة.
- عدم تغيير قاعدة البيانات أو المنطق المالي.
