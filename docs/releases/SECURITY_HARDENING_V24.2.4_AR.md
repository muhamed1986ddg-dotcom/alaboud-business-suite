# الإصدار v24.2.4 — استكمال تفعيل الصلاحيات وحماية الأخطاء

## إصلاحات الأمان

- حماية تنزيل النسخة الاحتياطية العادية بصلاحية `admin.only`.
- حماية النسخة الاحتياطية المشفرة والاستعادة بصلاحية `admin.only` مع فحص دفاعي داخل المسار.
- حماية تعديل إعدادات الإشعارات بصلاحية المدير، مع السماح بقراءتها لمن يملك صلاحية لوحة التحكم.
- تصنيف تقارير الأرباح والتقرير الشهري وملخص رأس المال تحت `reports.read`.
- تصنيف مساعد الذكاء الاصطناعي تحت `reports.read` لأنه لا يكتب بيانات مالية.
- تصنيف مسارات المطور والأجهزة وحالة الأمان كمسارات إدارية فقط.
- تصنيف قراءة هوية الشركة ضمن لوحة التحكم، وتعديلها كعملية إدارية.
- توسيع اختبارات الصلاحيات لمنع أي تراجع لاحق.

## استقرار الخادم

- الإبقاء على التغليف العام لجميع مسارات Express لالتقاط الأخطاء المتزامنة وغير المتزامنة.
- تمرير الأخطاء إلى معالج الأخطاء المركزي بدل تحولها إلى `unhandledRejection`.
- إرجاع `requestId` مع أخطاء الخادم لتسهيل تتبع المشكلة في Render Logs.
