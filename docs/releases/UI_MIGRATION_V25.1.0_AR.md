# v25.1.0 — ترحيل الواجهة المشتركة

## ما تم تنفيذه

- توسيع مكتبة `components/ui` بمكونات موحدة للحقول والقوائم والشارات وشريط الأدوات والتحميل والحالة الفارغة والترقيم.
- تطوير `AppTable` ليدعم حالة التحميل والحالة الفارغة والعرض كبطاقات على الهاتف.
- ترحيل صفحة التقارير والأرباح بالكامل إلى المكونات المشتركة.
- ترحيل نوافذ صفحة الديون العامة إلى `AppModal` وأزرار `AppButton`.
- إضافة قواعد تصميم موحدة للنماذج والجداول المتجاوبة.

## ما لم يتغير

- قاعدة البيانات.
- معادلات الأرباح والديون.
- صلاحيات المستخدمين.
- منطق الحوالات والدفعات.

## المرحلة التالية

ترحيل العملاء والحوالات وملف العميل تدريجيًا، ثم إزالة القواعد القديمة بعد التأكد أن جميع الشاشات لا تعتمد عليها.
