# تنظيف المشروع v24.0.4

تم حذف الملفات المؤكدة غير المستخدمة فقط، دون حذف ملفات التشغيل أو قاعدة البيانات أو ملفات GitHub Actions أو Android.

## المحذوف
- ملف الواجهة القديم `App_v16.0.15_FIXED.jsx`.
- اختبارات backend القديمة `selftest_v82` إلى `selftest_v87`، مع الإبقاء على الاختبارات المستخدمة فعليًا.
- نسخ مكررة من تعليمات وملفات تشغيل Render داخل backend، مع الإبقاء على النسخ المعتمدة داخل scripts.
- ملاحظات الإصدارات القديمة من v16 إلى v22 داخل docs/releases، مع الإبقاء على تقارير v23 وv24.

## ملاحظة أداء
هذا التنظيف يقلل حجم المستودع والنسخة المضغوطة، لكنه لا يغير وحده حجم حزمة JavaScript التي يحملها الهاتف. الملفات الأساسية الثقيلة المتبقية هي `frontend/src/App.jsx` و`frontend/src/styles.css`، ويجب تقسيمهما في مرحلة تحسين أداء منفصلة.
