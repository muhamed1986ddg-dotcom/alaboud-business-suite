# الإصدار v25.3.1 — استعادة اتصال PostgreSQL

- معالجة أخطاء 57P03 ووضع الاستعادة كأخطاء مؤقتة قابلة لإعادة المحاولة.
- ثماني محاولات افتراضية للكتابة مع تدرج زمني 0.5، 1، 2، 4، 8، 16 ثانية وحد أقصى قابل للضبط.
- إنشاء Pool جديد بعد انقطاع الاتصال بدل إعادة استخدام اتصال تالف.
- عدم إرسال نجاح الحفظ قبل تأكيد PostgreSQL.
- عند استمرار الانقطاع يعاد HTTP 503 ورسالة عربية واضحة، وتستعيد الذاكرة حالتها السابقة عبر mutateDurable.

متغيرات اختيارية:
- PG_WRITE_RETRIES=8
- PG_QUERY_RETRIES=6
- PG_RETRY_BASE_MS=500
- PG_RETRY_MAX_MS=16000
