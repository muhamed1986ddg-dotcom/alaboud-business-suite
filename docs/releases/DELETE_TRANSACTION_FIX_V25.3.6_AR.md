# v25.3.7 — إصلاح حذف الحوالات

- إصلاح حذف الحوالة من ملف العميل.
- إضافة زر حذف فعلي في قائمة الحوالات للهاتف والكمبيوتر.
- تحديث القائمة فورًا بعد نجاح الحذف ثم إعادة تحميلها من الخادم.
- مسح ذاكرة GET المؤقتة قبل إعادة التحميل.
- تأكيد الحذف الدائم قبل إعادة استجابة النجاح من API.
- حذف دفعات الحوالة المرتبطة حذفًا منطقيًا مع الحوالة.
- إضافة معالجة خطأ واضحة لمسار حذف الحوالة.
- إزالة تكرار بطاقات الحوالات على الهاتف.
