# الإصدار v24.2.3 — الأمان والهندسة

## الإصلاحات

- إضافة `.gitignore` يمنع الأسرار، ملفات البيئة، قواعد البيانات، النسخ الاحتياطية، مفاتيح التوقيع، السجلات ومخرجات البناء.
- السماح فقط بملفات الأمثلة الآمنة مثل `.env.example` و`examples/store.example.json`.
- إضافة `scripts/check-sensitive-files.js` وفحص إلزامي في GitHub Actions لمنع رفع الملفات الحساسة.
- نقل ملفات ملاحظات الإصدارات العربية من جذر المشروع إلى `docs/releases/`.
- نقل فرز وبحث قائمة العملاء إلى PostgreSQL عند تفعيل القراءة الأصلية.
- دعم `page/pageSize/limit/search/sort` في مسار العملاء مع fallback آمن للمتجر القديم.
- إضافة فهارس PostgreSQL للاسم، الهاتف، تاريخ الإنشاء ورقم العميل.
- إضافة رسائل خطأ عربية ورموز أخطاء لمساري قائمة العملاء وخيارات العملاء.
- استمرار الفرز المحلي كخطة احتياطية للأنواع المحسوبة مثل أعلى رصيد والأكثر تأخرًا.

## الاختبارات

نجحت فحوصات صياغة الخادم، الصلاحيات، الترحيل، Relational Projector، API Platform، الفروع والاستعداد للإنتاج.
