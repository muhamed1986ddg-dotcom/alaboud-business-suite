# v25.4.0 — Fast Durable Operations

- تأكيد الإضافة والتعديل والحذف فور اكتمال حفظ `app_state` الأساسي في PostgreSQL.
- نقل تحديث الجداول العلائقية الثانوية إلى طابور خلفي غير معيق للطلب.
- دمج تحديثات المرآة المتتابعة والاحتفاظ بأحدث نسخة فقط لتقليل الحمل.
- وضع ميزانية زمنية قدرها 12 ثانية لمحاولات حفظ الطلب التفاعلي عند انقطاع قاعدة البيانات.
- إنهاء رسالة الانتظار الطويلة خلال وقت محدد مع رسالة اتصال واضحة.
- لم يتم تحويل الحفظ إلى fire-and-forget: النجاح لا يزال لا يظهر إلا بعد حفظ المصدر الأساسي الدائم.
