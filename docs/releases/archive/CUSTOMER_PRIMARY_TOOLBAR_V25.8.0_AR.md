# v25.8.0 — شريط إجراءات العملاء الأساسي

تم نقل إجمالي دين العملاء من بطاقة منفصلة كبيرة إلى شريط الإجراءات الرئيسي في صفحة العملاء.

الترتيب المعتمد:

1. إضافة عميل
2. إضافة حوالة
3. إضافة دفعة
4. قائمة العملاء
5. إجمالي دين العملاء بالدولار الكندي

على الهاتف تظهر الأزرار في عمودين، ويظهر إجمالي الدين بعرض السطر كاملًا أسفلها.
