# الإصدار v25.6.0 — دفتر الشركات اليدوية

- إضافة نوع الشركة: مرتبطة أو يدوية.
- الشركة اليدوية تمتلك دفتر حساب مستقل.
- دعم الرصيد الافتتاحي، دين لنا، دين علينا، الدفعات وكشف الحساب.
- تثبيت قيمة CAD التاريخية لكل حركة حسب آخر سعر صرف آلي وقت التسجيل.
- إدخال الرصيد النهائي للشركات اليدوية في ملخص الشركات والدين العام والتقارير.
- عدم تشغيل المزامنة أو طلب بيانات دخول للشركات اليدوية.
