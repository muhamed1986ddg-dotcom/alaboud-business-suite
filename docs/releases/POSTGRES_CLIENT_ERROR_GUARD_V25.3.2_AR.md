# الإصدار v25.3.2 — حماية أخطاء عميل PostgreSQL

- إضافة مستمع `error` لكل عميل يتم سحبه من Pool قبل بدء المعاملة.
- منع مكتبة `pg` من تحويل انقطاع الاتصال إلى `uncaughtException` أثناء الكتابة.
- إعادة إنشاء Pool عند أخطاء الاتصال المؤقتة مع استمرار سياسة إعادة المحاولة.
- حماية عملاء الترحيل والتحقق والاسترجاع أيضًا.
- تغيير تسجيل الأخطاء المؤقتة في معالج العملية إلى تحذير واضح بدل وسمها كخطأ غير معالج.
