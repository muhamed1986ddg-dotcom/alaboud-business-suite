# v25.3.9 — Runtime Database Recovery

- منع إيقاف الخادم عند أخطاء PostgreSQL المؤقتة ذات الرمز DATABASE_TEMPORARILY_UNAVAILABLE أو الحالة 503.
- تصنيف الأخطاء المتداخلة عبر cause/originalError/parent.
- إبقاء الخدمة متاحة بعد انتهاء محاولات حفظ طلب واحد، مع إعادة 503 لذلك الطلب فقط.
- استمرار إيقاف الخادم للأخطاء البرمجية غير القابلة للتعافي.
- إضافة اختبار مستقل لتصنيف أخطاء قاعدة البيانات التشغيلية.
