# إصلاح صفحة العملاء المتأخرين — v24.2.1

- إزالة الخلفيات البيضاء من بطاقات العملاء المتأخرين.
- تحسين تباين الأرقام ومنع اختفائها.
- الرصيد المتبقي بالأحمر، إجمالي الحساب بالذهبي، وإجمالي المدفوع بالأخضر.
- عرض ثلاث بطاقات في صف الكمبيوتر، بطاقتين في الشاشات المتوسطة، وبطاقة واحدة على الهاتف.
- توحيد الحقول والفلاتر والرسائل مع الهوية الداكنة.
- عدم تعديل قاعدة البيانات أو الحسابات المالية.
