# الإصدار v24.0.9 — صفحة الميزانية الداكنة والنوافذ المنبثقة

- إزالة الخلفيات البيضاء من صفحة الميزانية.
- إضافة شريط وظائف: إضافة حركة، سجل الحركات، الأهداف المالية، تقرير الميزانية.
- نقل نموذج الإضافة والتعديل وسجل رأس المال والأهداف والتقرير إلى نوافذ منبثقة مستقلة.
- دعم الإغلاق بزر Esc أو الضغط خارج النافذة.
- منع قفل التمرير بعد إغلاق النافذة.
- تحسين ألوان الجداول والحقول والأرقام على الهاتف والكمبيوتر.
- لم يتم تعديل قاعدة البيانات أو المعادلات المالية.
