# v25.3.9 — Runtime DB DNS Recovery

## الإصلاحات
- اعتبار ENOTFOUND و EAI_AGAIN أخطاء اتصال مؤقتة قابلة للاستعادة.
- تشغيل منفذ HTTP فورًا حتى لا يفشل نشر Render أثناء تعافي DNS الداخلي.
- حجب مسارات API مؤقتًا برسالة 503 واضحة حتى اكتمال تهيئة PostgreSQL.
- إعادة محاولة تهيئة قاعدة البيانات بتدرج زمني دون إسقاط الخدمة.
- منع التحويل الصامت إلى ملف JSON المؤقت عندما تكون PostgreSQL مهيأة.
- توسيع `/api/health` لعرض حالة الجاهزية ومحاولة بدء التشغيل والخطأ الحالي.
- تحديث الإصدار إلى 25.3.9.

## ملاحظة
اسم المضيف الداخلي القصير الذي توفره Render مثل `dpg-...-a` صحيح داخل نفس المنطقة، ولا يحتاج إلى إضافة نطاق يدوي.
