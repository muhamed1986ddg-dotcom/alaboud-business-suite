# v25.3.9 — Render Private DNS Recovery

- اعتبار أخطاء DNS المؤقتة مثل ENOTFOUND وEAI_AGAIN أخطاء قابلة لإعادة المحاولة.
- إعادة محاولة تهيئة PostgreSQL والمهاجرات كاملة أثناء إعادة تشغيل قاعدة البيانات.
- فتح منفذ الويب فورًا وإبقاء الخدمة عاملة أثناء انتظار قاعدة البيانات.
- منع مسارات الأعمال مؤقتًا برسالة 503 واضحة حتى يصبح التخزين الدائم جاهزًا.
- منع التحول الصامت إلى ملف JSON مؤقت في بيئة الإنتاج.
- إضافة PG_STARTUP_RETRIES=20 لإعداد Render.
