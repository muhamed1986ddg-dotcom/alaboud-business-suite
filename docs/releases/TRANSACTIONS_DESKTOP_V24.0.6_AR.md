# v24.0.6 — سجل الحوالات الاحترافي

تم اعتماد التصميم الجديد لصفحة سجل الحوالات على الكمبيوتر.

## الحقول المضافة
- العملة الأصلية للحوالة.
- المبلغ الأصلي بعملة الحوالة.
- سعر الصرف مقابل CAD.
- القيمة المحولة إلى الدولار الكندي.
- العمولة بالدولار الكندي.
- المجموع النهائي بالدولار الكندي.
- الشركة والحالة والإجراءات.

## الملخصات
- عدد الحوالات.
- مجموع مبالغ حوالات USD.
- إجمالي القيمة المحولة إلى CAD.
- إجمالي الأرباح بـ CAD.

## الأدوات
- بحث برقم الحوالة أو المرجع.
- تصفية حسب الحالة والعملة والعميل والتاريخ.
- تصدير CSV.
- ترقيم صفحات.

لم يتم تغيير قاعدة البيانات أو طريقة حساب الحوالات.
