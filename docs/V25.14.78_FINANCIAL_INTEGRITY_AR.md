# v25.14.78 — سلامة الجرد والحسابات المالية

## القواعد المحاسبية المعتمدة

- صافي رأس المال = المال المضاف - المسحوبات + صافي الأرباح المحققة - توزيعات الأرباح.
- قيمة الجرد = الخزنة + أصول الشركاء + ذمم العملاء والشركات والذمم اليدوية لنا - جميع الذمم علينا.
- فرق الجرد = قيمة الجرد - صافي رأس المال، وهو مؤشر رقابي لا ينشئ تسوية آلية.
- المال المضاف لا يُجمع مع الخزنة مرة ثانية؛ مكانه الفعلي موجود أصلًا في الخزنة أو الأرصدة أو الذمم.

## أجور الحوالات

- وضع فرق السعر: الربح = مبلغ الحوالة × (سعر العميل - سعر التكلفة).
- وضع الأجرة المدفوعة: يستلم المستفيد كامل المبلغ، وتُضاف أجرة CAD المدفوعة مرة واحدة إلى ربح فرق السعر.
- مسار DEDUCT غير مسموح للحوالات الجديدة، والسجلات القديمة تُقرأ بتوافق آمن دون طرح CAD مباشرة من عملة أجنبية.

## منع التكرار

- إيصال العميل وتوزيعاته الفرعية يُحتسبان مرة واحدة في التقرير الشهري.
- الذمم اليدوية تُستبعد من الإجمالي فقط عند وجود customerId أو companyId/partnerId أو sourceRef مباشر يثبت الربط.
- تشابه الاسم وحده لا يحذف ولا يستبعد القيمة؛ يُظهر علامة «تحت المراجعة» فقط.
- لا حذف ولا تعديل آلي للسجلات التاريخية.

## التحقق

- اختبارات سلوكية رقمية مستقلة للجرد ورأس المال والدفعات والذمم وأرباح الحوالات.
- اختبار منع تكرار الدفعات متوافق مع Windows وLinux/Cloud Run.
- لا يتطلب هذا الإصدار migration لقاعدة البيانات.
