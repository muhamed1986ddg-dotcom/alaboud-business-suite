# v25.8.1 — تنظيف الأزرار المكررة

تم تخصيص صفحة الحوالات للعرض والمتابعة فقط.

حُذف منها:
- إضافة حوالة.
- إضافة دفعة واختصار التسديد.
- العملاء المتأخرون.
- إجمالي الأرباح.
- مجموع الحوالات غير المدفوعة.

وبقي فيها:
- جميع الحوالات.
- المدفوعة وغير المدفوعة.
- البحث والتصفية والتصدير.
- تعديل الحوالة وحذفها وفتح الفاتورة.

توجد عمليات الإضافة والدفع في صفحة العملاء، والمتأخرون في صفحتهم، والأرباح في صفحة الأرباح.
