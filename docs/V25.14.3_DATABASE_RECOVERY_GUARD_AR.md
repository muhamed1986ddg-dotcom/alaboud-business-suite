# v25.14.3 — حارس استعادة قاعدة البيانات

يعالج هذا الإصدار أخطاء PostgreSQL المؤقتة مثل `57P03` وعبارة `database system is not yet accepting connections`. ينتظر الخادم جاهزية PostgreSQL عبر فحص `SELECT 1` ضمن بوابة استعادة واحدة، ولا يعتمد أي عملية مالية قبل نجاح `COMMIT`. كما تُمنع الرسائل التقنية الإنجليزية من الوصول إلى المستخدم.

> ملاحظة: إذا كانت خدمة PostgreSQL نفسها متوقفة أو نائمة، لا يستطيع التطبيق منع الانقطاع الخارجي، لكنه ينتظر الاستعادة ويتعامل معها بأمان من دون فقد بيانات أو نجاح وهمي.
