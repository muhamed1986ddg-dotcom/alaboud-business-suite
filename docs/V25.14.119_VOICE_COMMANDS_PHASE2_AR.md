# v25.14.119 — تحديث شامل للأوامر الصوتية
- زر الصوت ثابت في جميع الصفحات.
- فتح الصفحات الرئيسية بالصوت.
- عرض المتأخرين.
- عرض رصيد العميل المفتوح.
- فتح آخر حوالة للعميل المفتوح.
- تحديث أسعار الصرف عبر فتح واجهة الأسعار للمراجعة.
- تجهيز تذكير واتساب للعميل المفتوح مع مراجعة قبل الإرسال.
- لا تنفيذ صوتي مباشر لعمليات مالية تغيّر البيانات.
