# v25.12.9 — استقرار استعادة PostgreSQL

- منع إنشاء عدة PostgreSQL Pools بالتزامن عند ظهور `57P03` أو انقطاع الاتصال.
- اعتماد استعادة Single-flight واحدة تشترك فيها جميع الطلبات المتزامنة.
- عدم استبدال الـPool الحالي قبل نجاح فحص `SELECT 1` على الـPool المرشح.
- تجاهل أخطاء Pools القديمة بعد استبدالها.
- إضافة حد زمني أدنى بين عمليات إعادة إنشاء الـPool لمنع حلقة إعادة الاتصال.
- إبقاء عمليات الكتابة غير معتمدة عند فشل قاعدة البيانات، مع إعادة المحاولة ضمن ميزانية زمنية محددة.
