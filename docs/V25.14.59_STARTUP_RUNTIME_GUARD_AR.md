# v25.14.59 — Startup Runtime Guard

هذا الإصدار تصحيحي فوق v25.14.57. أصلح انهيار Cloud Run عند بدء التشغيل بسبب حذف `mutate` من استيراد `store` مع استمرار استخدامه في `apiKeyMiddleware` و`integrationLogger`.

تمت إضافة اختبار Runtime يقوم بتشغيل `backend/src/server.js` فعليًا وينتظر استماع الخادم للمنفذ، حتى لا يمر مستقبلًا خطأ Runtime لا يكتشفه `node --check`.

لم يتم تغيير معادلات مالية أو أرصدة العملاء أو قارئ جاد أو بيانات قاعدة البيانات.
