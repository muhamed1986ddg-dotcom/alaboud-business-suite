# v25.14.19 — Database Write Readiness Gate

يعالج هذا الإصدار حالة بقاء طلبات `transactions` معلقة أثناء تعافي PostgreSQL.

- يمنع بدء الكتابة التفاعلية أثناء حالة إعادة الاتصال المعروفة، بانتظار قصير ومحدد فقط.
- يضيف مهلة JavaScript صلبة حول BEGIN وقيود المعاملة والكتابة وCOMMIT.
- لا ينفذ ROLLBACK على اتصال معروف أنه مكسور، لأن ذلك كان يستطيع إبقاء الطلب Pending حتى بعد انتهاء مهلة الاستعلام.
- يقلل مهلة طلبات الكتابة في الواجهة إلى 15 ثانية، ويعيد المحاولة بنفس `Idempotency-Key` فقط.
- لا يغيّر قاعدة أن نجاح العملية لا يُعلن إلا بعد COMMIT مؤكد أو العثور على receipt مؤكد لنفس العملية.
