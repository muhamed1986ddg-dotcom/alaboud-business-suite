# Android v25.14.74 — إصلاح الشاشة الفارغة عند التشغيل

## السبب

دوال `JavascriptInterface` في Android WebView تُستدعى على خيط خلفي وتكون متزامنة مع JavaScript. الإصلاح الأمني في v25.14.73 جعل `isBiometricEnabled()` يتحقق من أصل الصفحة بقراءة `webView.url` من خيط الجسر الخلفي. Android لا يسمح باستدعاء WebView إلا من خيط الواجهة؛ لذلك فشل أول رسم React وبقيت الخلفية الداكنة بلا صفحة دخول.

## الإصلاح

- حفظ حالة الثقة في متغير `@Volatile` لا يحتوي أي بيانات اعتماد.
- تحديث الحالة فقط من callbacks الخاصة بـWebView على خيط الواجهة.
- دوال الجسر تقرأ الحالة الآمنة ولا تصل إلى `webView.url`.
- الاستمرار في المطابقة التامة لمضيف Cloud Run الرسمي.
- مسح الثقة وفصل الجسر فور بدء صفحة غير موثوقة أو حدوث خطأ SSL أو خطأ تحميل رئيسي.
- إضافة اختبار انحدار يمنع إعادة القراءة غير الآمنة من خيط JavaScript Bridge.

هذا تحديث Android فقط. يبقى Web/Backend في الإنتاج على v25.14.73، ولا يحتاج Cloud Run إلى إعادة نشر.
