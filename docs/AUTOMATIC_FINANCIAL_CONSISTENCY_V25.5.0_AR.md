# v25.5.0 — توحيد الحسابات المالية الآلية

يعتمد تحويل الأرصدة الحالية للشركات والديون العامة إلى CAD على آخر سعر صرف آلي ناجح. لا يتم جمع مبالغ بعملات مختلفة قبل تحويل كل مبلغ بصورة مستقلة.

## قاعدة الحساب
- الرصيد الأصلي يبقى بعملته.
- الرصيد النهائي CAD = الرصيد الأصلي × آخر معامل تحويل آلي متاح.
- يعرض وقت ومصدر آخر سعر آلي.
- العمليات التاريخية التي تحمل cadAmount محفوظًا تبقى بقيمتها التاريخية ولا يعاد تسعيرها.
