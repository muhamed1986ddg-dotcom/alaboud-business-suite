# الإصدار 25.14.72 — استرداد تعارض الكتابة الآمن

- معالجة تعارض `STALE_STATE_REVISION` داخل الخادم بإعادة تحميل أحدث حالة من PostgreSQL ثم إعادة بناء العملية ومحاولة حفظها مجددًا.
- إبقاء عدد المحاولات محدودًا، وإبقاء حماية المراجعة المتفائلة ومفتاح منع تكرار العملية فعالين.
- عدم إعادة محاولة أخطاء التحقق المالي أو أخطاء الإدخال.
- إيقاف تحديث أسعار الصرف التلقائي بعد دقيقة من تشغيل كل مراجعة اختبارية؛ يستمر التحديث الدوري كل ساعة.
- إظهار رسالة عربية آمنة لمسارات دفعات العملاء بدل النص التقني الإنجليزي إذا استمر التعارض بعد المحاولات المحدودة.
- لا تغيير في معادلات الدفعات أو تخصيصها أو الحسابات المالية.
