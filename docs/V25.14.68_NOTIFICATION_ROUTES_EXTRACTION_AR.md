# v25.14.68 — Architecture Stage 3

## نطاق الإصدار

استخراج مجموعة مسارات الإشعارات من `backend/src/server.js` إلى الوحدة المستقلة:

`backend/src/routes/notifications.js`

وتشمل المجموعة:

- قراءة وتعديل إعدادات الإشعارات.
- إنشاء قائمة الإشعارات الحالية.
- تسجيل إجراءات متابعة العملاء.
- قراءة سجل إجراءات المتابعة لكل عميل.
- إنشاء ملخص تنبيهات العملاء المتأخرين.

## ضمانات عدم تغيير السلوك

- بقيت المصادقة مطلوبة لكل المسارات الستة.
- بقي تعديل إعدادات الإشعارات محميًا بصلاحية `admin.only`.
- بقي ترتيب تسجيل المسارات بين لوحة التحكم ونظرة رأس المال كما هو.
- لم تُنقل أو تُعدّل أي معادلة مالية؛ تستقبل الوحدة دوال الملخص والتحويل الحالية بحقن الاعتماديات.
- لم تتغير مسارات API أو أشكال الاستجابات.
