# v25.13.0 — استعادة اتصال قاعدة البيانات

- جميع الطلبات تنتظر محاولة استعادة واحدة مشتركة بدل الاستمرار باستخدام Pool معروف أنه متعطل.
- لا تستأنف الاستعلامات أو عمليات الحفظ قبل انتهاء بوابة الاستعادة.
- يحتفظ النظام بآخر Snapshot للمرآة العلائقية عند الانقطاع ويعيد المحاولة بتأخير محدود.
- تُحوّل الأخطاء التقنية مثل `Connection terminated unexpectedly` و`57P03` إلى رسالة عربية آمنة.
- تُرسل الواجهة حالة إعادة الاتصال بدل عرض تفاصيل PostgreSQL للمستخدم.
- لا تُعرض رسالة نجاح لأي كتابة غير مؤكدة.

ملاحظة: انقطاع خدمة PostgreSQL نفسها لا يمكن منعه من داخل التطبيق، لكن هذا الإصدار يمنع عاصفة الطلبات، ويحمي المستخدم من الرسائل التقنية، ويجعل الاستعادة متسلسلة وآمنة.
