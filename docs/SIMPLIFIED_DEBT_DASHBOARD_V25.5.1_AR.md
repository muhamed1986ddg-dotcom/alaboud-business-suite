# v25.5.1 — تبسيط صفحة الدين العام

تم تحويل صفحة الدين العام إلى لوحة أرقام فقط دون إظهار أسماء العملاء أو الشركات.

- إجمالي الدين لنا
- إجمالي الدين علينا
- الصافي النهائي
- ملخص العملات
- أعداد الديون المفتوحة والمتأخرة والمسددة
- عند اختيار الدين لنا يظهر رصيد دين العملاء، الرصيد النهائي للشركات، والمجموع الكلي فقط.
