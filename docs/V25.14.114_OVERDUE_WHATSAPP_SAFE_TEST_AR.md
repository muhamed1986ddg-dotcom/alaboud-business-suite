# v25.14.114 — اختبار آمن لرسائل العملاء المتأخرين

- اختيار عميل متأخر واحد فقط.
- معاينة بياناته والرسالة.
- اختيار التذكير الأول أو الثاني.
- إرسال الاختبار للعميل المحدد فقط.
- الاختبار لا يُسجل كتذكير رسمي FIRST/SECOND ولا يؤثر على دورة 7/15.
- لا إرسال جماعي أثناء الاختبار.
- لا تغيير على المحاسبة أو الخزنة أو الأرصدة أو منطق التصفير.
