# الإصدار 25.14.71 — محاذاة أزرار قائمة العملاء

- وضع زر «تصفير الحساب» مباشرة بجوار زر «فتح الحساب».
- جعل زر التصفير بنفس عرض وارتفاع بقية أزرار بطاقة العميل.
- تثبيت ترتيب الأزرار: فتح الحساب، تصفير الحساب، تعديل، حذف.
- الحفاظ على وظيفة تصفير الحساب وجميع الوظائف الحالية دون تعديل البيانات أو الحسابات المالية.
- إضافة اختبار انحدار يمنع عودة زر التصفير إلى صف كامل.
