# v25.14.45 — تحديث الحساب القديم مباشرة

يعالج هذا الإصدار حالة نجاح الحفظ في الخادم مع بقاء بيانات قديمة في واجهة العميل بسبب ذاكرة GET المؤقتة. بعد تغيير الحساب القديم يتم مسح الكاش، تحديث العميل فورًا من استجابة الخادم، ثم إعادة جلب البيانات. كما يتم مسح كاش القراءات بعد عمليات العميل المؤثرة ماليًا لضمان اتساق الصفحات المرتبطة عند فتحها أو إعادة تحميلها.
