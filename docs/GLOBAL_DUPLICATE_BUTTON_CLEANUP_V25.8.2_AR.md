# v25.8.2 — تنظيف الأزرار المكررة على مستوى التطبيق

## النتيجة

تم اعتماد مسؤولية واضحة لكل صفحة بدل تكرار نفس الإجراء في عدة أماكن.

- صفحة العملاء هي مركز إضافة العميل والحوالة والدفعة.
- صفحة الحوالات مخصصة للعرض والبحث والفلترة والتعديل والحذف.
- صفحة المتأخرين مخصصة للتحصيل والمتابعة.
- صفحة الأرباح مخصصة للأرباح والتقارير.
- صفحة الشركات مخصصة للشركات والدفاتر والمزامنة.
- صفحة الدين العام مخصصة للملخص وإدارة الديون العامة.

## ما تم حذفه في هذا الإصدار

تم حذف شريط الاختصارات المكرر من لوحة التحكم، لأنه كان يكرر أزرار إضافة حوالة وعميل ومصروف وفتح التقارير وأسعار الصرف الموجودة في صفحاتها الأصلية.

كما تم حذف CSS المرتبط بالشريط المحذوف لمنع تراكم كود واجهة ميت.

## ما لم يتم حذفه

تم الإبقاء على الإجراءات السياقية الضرورية، مثل تعديل أو حذف سجل محدد، تسجيل دفعة لعميل متأخر، فتح كشف حساب، أو مزامنة شركة، لأنها تخص السجل الحالي وليست اختصارات عامة مكررة.
