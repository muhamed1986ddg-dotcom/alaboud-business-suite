# v25.14.122 — استعادة تأكيد الدفعات بشكل موثوق

## الهدف
إزالة حالة ظهور رسالة انقطاع/فشل عند تسجيل دفعة بينما تكون الدفعة قد تم اعتمادها فعليًا في PostgreSQL.

## ما تم إصلاحه
- رفع مهلة عمليات الكتابة من 12 ثانية إلى 30 ثانية.
- إضافة تحقق متدرج ومحدود لحالة العملية بعد انقطاع الرد: 500، 1000، 1500، 2500، 4000 مللي ثانية.
- لا يتم إعادة POST المالي تلقائيًا مطلقًا.
- يبقى `Idempotency-Key` الأصلي هو مرجع التحقق.
- إذا كانت الحالة COMMITTED/SUCCESS/COMPLETED تعامل العملية كنجاح وتُحدّث بيانات العميل.
- إذا كانت FAILED/REJECTED/ROLLED_BACK تظهر رسالة فشل مؤكدة.
- إذا بقيت الحالة مجهولة تظهر رسالة تطلب تحديث حساب العميل قبل المحاولة مرة أخرى.
- حماية مباشرة من الضغط المكرر على زر حفظ الدفعة.
- حماية تحديثات React بعد unmount في مسار الدفعات.
- Android: `versionName=25.14.122`, `versionCode=2514122`.
- إصلاح مرجع `check:current` ليستخدم اختبار اتساق 122، مع توافق Docker/Cloud Build.

## الثوابت
لم تتغير معادلات الرصيد أو الأرباح أو توزيع الدفعة، ولم تتم إضافة إعادة إرسال تلقائي لأي عملية مالية.
