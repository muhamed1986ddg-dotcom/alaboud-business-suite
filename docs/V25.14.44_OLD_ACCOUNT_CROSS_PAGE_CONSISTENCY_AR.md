# v25.14.44 — اتساق الحساب القديم في جميع الصفحات

هذا الإصدار يضمن أن الحساب القديم للعميل يظهر ويُحسب باتجاهه الصحيح في الصفحات المرتبطة.

- **عليه / RECEIVABLE**: يضاف إلى دين العملاء لنا ويرفع الرصيد المستحق على العميل.
- **له / PAYABLE**: يصنف كدين للعميل علينا ويخفض صافي الرصيد/رأس المال بحسب المعادلات الموحدة.
- قائمة العملاء تعرض الحساب القديم واتجاهه والرّصيد النهائي فور الحفظ.
- ملف العميل وكشف الحساب يحتفظان بنفس الاتجاه.
- الدين العام والميزانية والجرد الشهري تعتمد `FinancialEngine.customerBalanceTotals` للفصل بين المستحق لنا والمستحق علينا.
- لوحة التحكم لم تعد تخلط الرصيد السالب داخل إجمالي المستحقات.
- مسار PostgreSQL الأصلي يحترم `oldBalanceType` عند حساب الرصيد.
- رسالة كشف الحساب عبر واتساب تستخدم الحساب القديم بالاتجاه الصحيح.

لا يوجد تحويل أو حذف للبيانات القديمة؛ التغيير يخص العرض والتصنيف والحساب فقط.
