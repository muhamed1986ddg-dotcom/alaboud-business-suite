# v25.10.0 — سلامة الحفظ والمحرك المالي

- العمليات التي تستخدم `mutateDurable` لا ترجع نجاحًا قبل تأكيد PostgreSQL.
- استرجاع نسخة الذاكرة السابقة عند فشل الحفظ.
- محرك مالي مركزي لحساب رصيد العميل وإجمالي دين العملاء.
- نقل مسارات الصحة والتوثيق إلى وحدة Routes مستقلة.
- نقل شريط أدوات العملاء وعناصر البحث والفرز إلى مكونات مستقلة.
- جميع أنواع فرز العملاء أصبحت خادمية عبر PostgreSQL.
- تحديث قائمة العملاء محليًا فور نجاح الإضافة ثم إعادة تحقق صامتة.
- اختبار E2E يغطي الإضافة والقراءة بعد الكتابة والحوالة والدفعة والتعديل والحذف وتطابق الرصيد.
- أرشفة ملاحظات الإصدارات القديمة وإزالة الملفات المتطابقة غير الضرورية.
