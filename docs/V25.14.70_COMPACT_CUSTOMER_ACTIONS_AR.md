# الإصدار 25.14.70 — تصغير أزرار حساب العميل

- جعل جميع إجراءات أعلى صفحة حساب العميل أزرارًا صغيرة بدل تمددها بعرض الصفحة.
- وضع مشاركة صورة كشف الحساب وحفظ الصورة ضمن مجموعة صغيرة متجاورة مع بقية الإجراءات.
- السماح للأزرار بالانتقال إلى سطر ثانٍ عند ضيق الشاشة دون تمديد أي زر بعرض كامل.
- الحفاظ على الرجوع، كشف الحساب، إضافة حوالة، رسالة واتساب، مشاركة الصورة، وحفظ الصورة.
- إضافة اختبار انحدار يمنع عودة زر مشاركة الصورة إلى العرض الكامل.
