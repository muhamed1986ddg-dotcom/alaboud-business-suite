# العبود للأعمال — الإصدار 25.14.73 للأمان وموثوقية الجلسات

هذه نسخة مصدر كاملة ونظيفة للإصدار 25.14.73. الحزمة النهائية لا تحتوي على `node_modules` أو مخرجات البناء أو بيانات التشغيل أو ملفات البيئة والأسرار.

## أهم الإصلاحات

- إغلاق ثغرة قبول أي نطاق ينتهي بـ `run.app` داخل Android WebView.
- عدم كشف رمز البصمة طويل الأمد إلى JavaScript، وتنفيذ المصادقة الأصلية داخل Android.
- إصلاح الحفظ الفعلي للمستخدمين والفروع والجلسات على مستوى الشركة.
- إبطال الجلسات والبصمة عند الخروج وتغيير/إعادة تعيين كلمة المرور وتعطيل الحساب.
- منع كلمة مرور المدير الافتراضية والتسجيل العام في بيئة الإنتاج.
- حماية موصلات الشركات من SSRF وتحويلات الشبكات الخاصة وتجاوز شهادات TLS.
- ترقية التبعيات حتى أصبحت نتيجة تدقيق npm صفر ثغرات معروفة.
- تنظيف ملفات التوثيق والاختبارات الميتة، وتثبيت مسح 101/101 اختبار خلفي داخل CI، وإصلاح بوابة UI المشتركة.

التقرير الكامل، بما فيه الملفات المكررة ونقاط القوة والضعف وخطة نجاح التطبيق، موجود في `docs/FULL_PROJECT_AUDIT_V25.14.73_AR.md`.

## الفحص المحلي

من PowerShell داخل مجلد المشروع:

```powershell
npm ci --prefix backend --include=dev --ignore-scripts --no-audit --no-fund
npm ci --prefix frontend --include=dev --ignore-scripts --no-audit --no-fund
npm test
```

## النشر الآمن إلى Cloud Run

بعد نجاح الفحوصات:

```powershell
.\DEPLOY_CLOUD_RUN_V25_14_73.ps1
```

السكربت يستخدم `--no-traffic`، ولذلك لا يحول المستخدمين إلى النسخة الجديدة. اضبط `INITIAL_ADMIN_PASSWORD` بسر قوي و`JWT_SECRET` فريد و`DATABASE_URL` قبل الاختبار. بعد اجتياز smoke test، حوّل الحركة يدويًا مع إبقاء مراجعة 25.14.72 جاهزة للرجوع.
